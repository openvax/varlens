varlens.fusions module

Supplied fusion RNA -> Isovar evidence -> Topiary protein fragments.

This adapter does not discover fusions from BAMs or infer a coding frame from gene names. Isovar validates the supplied sequence, mappings, references and read observations, retaining every supported frame and unresolved outcome.

varlens.fusions.analyze_fusion(payload, *, alleles=(), epitope_lengths=(8, 9, 10, 11), min_fragments=2, predictor=None)[source]

Return a JSON-serializable reconstruction, fragments and predictions.

payload follows Isovar’s supplied-fusion input contract (fusion, references, reads, optional reference_names). The Sid fixture envelope fields note and original_records are preserved but not passed to Isovar as evidence. Unknown fields are rejected by Isovar.

All coding hypotheses, including ambiguous/partial-CDS hypotheses, become separately identified fragments. Their status is carried onto prediction rows; no hypothesis is selected as the true protein. No alleles/predictor means reconstruction only. predictor may be a configured TopiaryPredictor for a Python caller; otherwise supplied alleles select mhctools.NetMHCpan.

varlens.mhc_binding module

varlens.mhc_binding.binding_affinities(variants, alleles, epitope_lengths=(8, 9, 10, 11))[source]

Return each variant’s lowest mutant-peptide affinity (nM) and allele.

Variants without an affinity prediction have a missing affinity and allele. Topiary’s presentation scores are deliberately excluded from this summary.

varlens.mhc_binding.fragment_predictions(fragments, alleles=(), epitope_lengths=(8, 9, 10, 11), *, predictor=None)[source]

Predict target-overlapping peptides, retaining all fragment metadata.

Unlike the small-variant best-affinity summary, this returns Topiary’s full prediction rows, with score kinds, fragment/sample identity and evidence. Target overlap is not a claim of proteome-wide novelty.

varlens.sequence_context module

varlens.sequence_context.variant_context(reference_fasta, contig, inclusive_start, inclusive_end, alt, context_length)[source]

Retrieve the surronding reference region from a variant.

SNVs are canonicalized so the reference base is a pyrmidine (C/T). For indels the reverse complement will still be taken if the first base of the reference is not a pyrmidine, but since the reference will also be reversed, that doesn’t guarantee it will start with a pyrmidine.

Parameters:

reference sequence from pyfaidx package

contigstr

Chromosome of the variant

start of the variant in 1-based inclusive coordinates

end of the variant in 1-based inclusive coordinates

alt sequence

number of bases on either side of the variant to return

mutation - the ref sequence followed by a > character followed by the

the alt sequence

varlens.support.variant_support(variants, allele_support_df, ignore_missing=False)[source]

Collect the read evidence support for the given variants.

Parameters:
variantsiterable of varcode.Variant
allele_support_dfdataframe

Allele support dataframe, as output by the varlens-allele-support tool. It should have columns: source, contig, interbase_start, interbase_end, allele, and count (the number of supporting reads).

ignore_missingboolean

If True, variants with no allele counts have zero depth. Otherwise missing counts raise ValueError.

Returns:
pandas.DataFrame

Rows are variants; columns have two named levels, measurement and source. Metrics are num_alt, num_ref, num_other, total_depth, alt_fraction, and any_alt_fraction. For example, frame["num_alt"] selects all sources’ alternate-read counts.
